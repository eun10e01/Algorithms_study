### 문제 설명

<p>어릴적 수학 시간에 오른쪽 자리수에서 왼쪽 자리의 숫자끼리 더하는 방법을 배운다. <br>
이러한 과정 중에서 '자리 올림' - 10이상의 숫자가 나와서 다음 자리에 1을 더해주는 것 - 이 발생 하는 것을 알 수 있다.<br>
2개의 숫자가 들어왔을 경우, 몇 번의 자리 올림이 발생하는지 알아보는 프로그램을 작성하라.</p>

### 입력 

<p>한 줄에 2개의 정수가 입력된다. 10자리 이하의 숫자이다.</p>

### 출력 

<p>2개의 숫자를 더했을 때 자리올림이 일어나지 않을 경우 "No carry operation." 이라 출력하고 <br>
1번의 자리올림이 일어났을 경우 "1 carry operation.", <br>
그리고 n번의 자리올림이 일어 났을 경우 "n carry operations."라고 출력한다..</p>
