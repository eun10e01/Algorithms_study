### 문제 설명

<p오름차순의 순서대로 정렬되어 있는 N개의 데이터에서 특정한 숫자가 몇 번째 위치에 있는지를 알아내는 프로그램을 작성하시오.<br>
각 데이터 값의 범위는 정수범위이다.</p>

### 입력 

<p>첫 줄에 N이 주어진다.<br>
N은 정렬되어 주어지는 데이터의 수이다.(1≤N≤50,000)<br>
둘째 줄에는 N개의 서로 다른 정수 Ai가 정렬되어 주어진다. 각 수 Ai는 공백 하나로 분리되어 주어진다. ( Ai는 int범위의 정수)<br>
셋째 줄에는 데이터에서 찾아야할 특정한 수의 개수 T가 주어진다. 즉, T가 3이면 3개의 수를 정렬된 데이터에서 찾아야 한다.(1≤T≤10,000)<br>
넷째 줄에는 T개의 수가 공백 하나로 분리되어 주어진다.</p>

### 출력 

<p>찾아야할 수가 정렬되어 주어진 데이터의 수중에서 앞에서부터 몇 번째에 있는지 그 위치를 출력한다.<br>
첫 번째 위치는 1이다. 만약, 찾으려는 수가 주어지는 데이터에 존재하지 않는다면, 0을 출력한다.</p>
