### 문제 설명

<p>정보올림피아드 예선을 맞아 전국에서 수많은 수험생이 원서를 접수하였다. 담당자는 지역별 모인 수험표를 모아 수험번호 순으로 정렬하고자 한다. 어떻게 하면 빠른 시간 내에 정렬할 수 있을까? 수험번호는 이미 정렬되어 있을 수도 있고 아닐 수도 있다.</p>

### 입력 

<p>첫 줄에는 데이터의 개수 N과 정렬 방법 M이 공백을 두고 입력된다. 두 번째 줄에 N개의 숫자가 공백으로 구분되어 입력된다. (1≤N≤500,000, M이 1일 때 오름차순, 2일 때 내림차순이다. 1≤N개의 입력데이터 ≤21억)</p>

### 출력 

<p>한 줄에 하나의 숫자를 N줄에 걸쳐 출력한다.</p>
