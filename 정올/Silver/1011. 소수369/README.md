### 문제 설명

<p>원래 기존의 369게임은 원으로 둘러앉아서 순서대로 1부터 순서대로 숫자를 부르면서 3, 6, 9가 들어가는 숫자를 부를 경우 숫자 대신 박수를 쳐야하는 게임이다.<br>
소수369게임은 박수를 치는 수를 3, 6, 9가 들어가는 숫자 대신 소수(1이외에 자기 자신으로만 나눠지는 2이상의 숫자)로 바꿔서 진행하는 게임이다.<br>
플레이어의 수와 마지막에 부른 번호가 주어졌을 때 특정 사람이 박수를 몇 번 쳤는지 알아보는 프로그램을 작성하라.</p>

### 입력 

<p>첫 줄에 학생 수 N, 마지막에 부른 숫자 M, 박수를 몇 번 쳤는지 알고 싶은 사람의 번호 K가 주어진다.<br>
첫 번째 숫자를 부르는 학생은 0번이고, 마지막 학생은 N-1번이며 N-1번 학생 다음에는 0번 학생의 차례가 오게 된다.</p>​

### 입력 제한
- 2≤N≤1,000
- 1≤M≤1,000,000
- 0≤K＜N

### 출력 

<p>해당 번호의 사람이 박수를 치는 횟수를 출력하라.</p>
