### 문제 설명

N개의 자연수들로 이루어진 수열 A가 있다.<br>
두 수로 이루어진 모든 쌍의 합들이 주어질 때 A를 구하는 프로그램을 작성하여라.

### 입력 

첫 번째 줄에는 N이 주어진다. (2 ≤ N ≤ 1,000) 두 번째 줄부터 N개의 줄에는 아래 형식에 맞게 N개의 100,000 이하의 자연수가 주어진다. 1+i 줄부터 j번째 수를 K라고 할 때, i＝j 이면 K＝0 이고, i≠j 이면 K＝A[i]+A[j] 이다.

### 출력 

A[1]에서 부터 A[N]까지 순서대로 출력한다. 답은 유일하다고 가정해도 좋다.
