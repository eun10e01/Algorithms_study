### 문제 설명

<p>A...Z의 피연산자들로 이루어진 후위표기식이 주어졌을 때, 그 결과 값을 출력하는 프로그램을 작성하시오.<br>
후위표기식의 각 연산자는 오직 '+', '-', '*', '/'으로만 이루어져 있는데, '/'는 나눈 몫을 의미한다.<br>
만약 0으로 나누는 상황이 발생한다면 "ZeroDivisionError"를 출력한다.</p>

### 입력 

<p>첫 줄에 A...Z의 각 값이 의미하는 수가 주어진다. (1 ≤ A...Z ≤ 50)<br>
두 번째 줄에 후위표기식이 주어진다. 후위표기식의 길이는 10을 넘지 않으며 오직 대문자 알파벳과 '+', '-', '*', '/'로만 이루어져있다.</p>

### 출력 

<p>첫 줄에 계산 결과를 출력한다.<br>
만약 0으로 나누는 상황이 발생한다면 "ZeroDivisionError"를 출력한다.</p>
