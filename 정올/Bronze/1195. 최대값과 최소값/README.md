### 문제 설명

10개의 정수와 기준 정수를 입력받고 기준 정수보다 큰 수중 가장 작은 수와 기준 정수 보다 작은 수중 가장 큰 수를 구하시오.

### 입력 

첫 번째 줄에 10개의 1이상 1 000 이하의 정수가 공백으로 구분하여 입력된다.<br>
두 번째 줄에 기준 정수 n(1 ≤ n ≤ 1 000)이 입력된다.

### 출력 

첫 줄에 기준 정수보다 작은 수중 가장 큰 수를 두 번째 줄에 기준 정수 보다 큰 수중 가장 작은 수를 출력한다.<br>
만약 해당하는 값이 없는 경우 기준 정수를 출력한다.
